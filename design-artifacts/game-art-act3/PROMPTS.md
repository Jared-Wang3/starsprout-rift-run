# Act III image-generation prompts

Generated with the built-in `image_gen` tool. Existing game art was supplied as a style reference; all new scenes and characters were requested as original designs.

## `environments-c-source.png`

Create a 2×2, equal-cell, full-bleed environment atlas matching the established layered hand-cut paper diorama and screen-print style. The four panels are: a copper storm clocktower above rain clouds; an impossible folded-paper dream library with luminous ink rivers; an aurora-lit crystalline frost garden; and a cosmic rift-loom sanctum. Keep each panel readable behind side-scrolling gameplay, with strong landmarks, open gameplay bands, no characters, no labels, no gutters, no watermark, and no repeated scene.

## `boss-weaver-chroma.png`

Create an exact 4×2 boss sprite atlas on a perfectly flat solid `#ff00ff` chroma background. The original Rift Weaver is an eight-legged origami spider-moth automaton made from navy paper armor, brass loom rings, cyan crystal joints, coral thread spools, and a star-shaped core. Eight states: idle, thread charge, lateral dash, cocoon shield, loom beam, stunned, core exposed, defeated. Use equal cells, consistent proportions and lighting, generous padding, crisp isolated edges, no shadows, text, grid lines, logos, or watermark; never use the chroma color inside the character.

## `act3-collectibles-chroma.png`

Create an exact 2×2 collectible atlas on a perfectly flat solid `#ff00ff` chroma background, matching the premium paper-collage icon style. Icons: a glowing Lumen Spore lantern with three motes; a sun/moon hourglass Time Shard; a brass Storm Cell with a lightning bolt; and a star-shaped Rift Core Seed held inside a coral-thread loom ring. Use distinct silhouettes, equal scale, crisp isolated edges, no shadows, text, grid lines, logos, or watermark; never use the chroma color inside the icons.
